# 2026 年 9 月：管理流程與本機資料

本次新增的操作流程：Skill 庫、連接 AI、驗證連接、管理 Skill。既有歷史文件描述舊實作，不代表目前介面。

## 修改 Skill

1. 選擇 Skill，到「管理 Skill」。
2. 「1 用途」：填這個 Skill 幫你做甚麼。結構大綱另可填輸入種類、整體完成要求。
3. 「2 步驟」：點步驟名稱，修改指示。每個欄位附意義及例子。勾選才會交給 AI；上移、下移改變順序。已有分項設定的步驟會顯示其行動規則。
4. 詳細 ReAct、輸出與停止條件、附加工具按需要展開。腳本先保存檔案，再加入目前步驟，填執行方法，最後保存 Skill。
5. 「3 檢查並保存」：確認選中步驟和生成內容，再保存。預覽不會更新磁碟；保存完成後 MCP 下次讀取才取得新版本。

Markdown Skill 在第二步直接修改指示；完整原始碼放在進階區，保留既有格式。切換 Skill 會載入它自己的資料。

## 資料與 Git

`.promptforge/`、`.agents/skills/` 和舊本機 `workbench-projects.json` 停止 Git 追蹤，實體檔案保留。本次以新增 commit 記錄，沒有改寫舊歷史；舊 commit 仍包含當時的資料。

Git 保留版本 1 格式定義、三份可重用範本和初始化腳本。執行 `scripts/init-local-data.ps1` 建立缺少的 PromptForge 與 PromptForge-context 管理大綱；不覆蓋已有檔案。新建後在 Web 保存，產生 agent 版本。
