# Skill 內容功能完成計劃

2026 年 9 月重整的後續修正；視覺方向等待使用者選擇開源 sample。

## 實作範圍

1. 共用本地 Skill 發現機制，GUI 與 MCP 都能列出實際 Skill。
2. 每個 Skill 獨立讀取、編輯、保存；結構化大綱只生成所選步驟，既有 Markdown 保留原格式。
3. 將業務指示、輸入、輸出及驗收要求保存在專案資料，移除前後端寫死的特定 Skill 流程。
4. 保留現有 PromptForge / context 行為、支援檔案與上一份可用產物；較新修改應回報衝突。
5. 新增及保存後，MCP 下次呼叫即讀取最新產物。

## 驗收與交付

- 三個現有 Skill 都在 GUI 可見，且可個別使用與編輯。
- 修改 context 後再保存 PromptForge，不得覆蓋 context。
- 新 Skill 保存、重開、MCP 列出及讀取均成功。
- 未選步驟不生成；衝突或生成失敗保留舊版本。
- 測試通過後核對實際 GUI 與 agent MCP 讀取，再部署及新增 commit。
- 保留既有歷史及不相關未提交文件。

Luna 負責實作及程式測試；主 agent 負責範圍檢查、實際入口驗收與部署。此計劃不是完成證明。
