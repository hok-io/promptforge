## Product decisions

- Four stable destinations: 開始使用, 連接 AI, 驗證連接, 管理 Skill. URL hash navigation supports bookmarks and browser Back.
- The initial view offers a task input and an agent invocation to copy, with actual saved step names. It does not claim to run AI in the browser.
- The global Skill picker scopes use, editing and verification consistently.
- Editing keeps selected-only generation. ReAct details, file resources and generated source are progressively disclosed. Save links to use/verify afterward.
- Connection instructions separate service reachability from client configuration and a real MCP read.
- Verification creates a 15-minute in-memory challenge bound to one saved generated revision. `get_skill` accepts optional `verificationCode`; a matching actual read records a receipt. Web ping and untagged reads cannot mark success. Update or restart invalidates evidence. The receipt proves a token-bearing MCP read, not client identity or task correctness.
- Agent result acceptance remains an explicitly manual checklist from the Skill's output/stop conditions; PromptForge and context criteria include the required ReAct and context distinctions.
- No remote fonts or new UI dependencies. Existing local green identity retained, 16px base font, restrained borders, responsive navigation and reduced-motion support.
