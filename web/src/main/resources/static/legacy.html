下表是既有實作的作用、與新目標的關係，以及刪除影響。這次沒有刪除舊資料或舊功能。新 GUI 的管理來源與 Skill 生成不依賴下面的業務流程。

既有功能現有作用與新流程關係刪除影響／共用依賴
手動拼 Prompt人手編排區塊、規則與知識卡並保存。與新選擇式生成平行；新 GUI 不讀舊 prompt。舊 prompt 編輯與預覽失效；規則、知識載入器仍被舊功能共用。
固定釐清問卷保存問題與輸出偏好，組合任務文字。新 Skill 按任務自行判斷是否追問。舊問卷頁與 profile 不再可用；保存底層與其他功能共用。
評估匯入記錄外部測試或模型意見及證據。新生成器目前不讀評估紀錄。舊評估紀錄無法從 Web 匯入／查看；與舊 Skill 管理共用。
Skill 匯入、審核、批准、啟用與匯出管理舊 Skill bundle 的版本與狀態。不控制新 repo 內的兩個生成入口。舊匯入 Skill 的操作入口失效；解析與檔案工具有共用。
多專案登記讓舊工作台選擇範例及已登記專案。新 program 固定保存在 PromptForge repo。舊規則、知識、prompt 與 Skill 頁失去專案入口；舊 Web service 廣泛共用。
CLI 與 prompt-frame Skill文字規則選擇及本地檢索。可獨立使用；新 program 不自動引用。現有 CLI 使用者受影響；core 規則與知識檔案共用。

保留舊功能時，請從舊工作台使用。刪除決定仍由你逐項確認；技術清單另見 docs/2026-09-program.md。
