    直接用本地 Skill，不經 MCP
    新增或修改後須重新發現。斜線入口由客戶端決定。MCP 每次呼叫讀取保存版；已讀過的內容要再次呼叫才會更新。
    

    

    

    驗證連接
    看到回執，才知道 AI 讀到。
    此測試驗證 MCP 讀取目前保存的 Skill。任務結果是否正確，仍要按下面的輸出要求檢查。
    

    連接驗證
    尚未開始
    1. 按「產生測試句」。
    2. 複製並貼到你的 AI 對話，讓 AI 呼叫工具。
    3. 回來查看結果；等候期間每 3 秒更新。
    

    等待 MCP 讀取
    有效 15 分鐘；重啟服務後失效。回執證明帶驗證碼的 MCP 呼叫已讀取此版本，不識別是哪個客戶端，也不代表 AI 已正確完成任務。
    

    一直等候，應該點做？
    • AI 說沒有工具：回到「連接 AI」，檢查設定後開新工作階段。
    • AI 只回覆文字：請它實際呼叫 get_skill，並傳入測試句的 verificationCode。
    • 顯示版本已變更：重新產生測試句，驗證最新保存版。
    返回連接步驟 →

      Skill 的用途
      小寫英文、數字及連字號。建立後用這個名稱呼叫 Skill。
      

      步驟大綱 0
      目前提供 0 步給 AI；點名稱可編輯。
      

      

      腳本與參考資料（選用）
      先保存檔案，再加入目前步驟，最後保存 Skill。腳本由有相應工具與權限的 AI 執行。
      腳本用 scripts/；背景資料用 references/；文字模板用 assets/。例如 references/rules.md。
      Web 不會執行腳本或安裝 runtime。圖片等二進位素材未支援上傳。
