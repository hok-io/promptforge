    驗證連接
    測試 MCP 連線
    確認 AI 能否透過 MCP 讀取你選擇的 Skill。
    

    連接驗證
    尚未開始
    1. 按「產生測試指令」。
    2. 複製並貼到你的 AI 對話，讓 AI 呼叫工具。
    3. 回來查看結果；等候期間每 3 秒更新。
    

    等待 MCP 讀取
    測試指令有效 15 分鐘，重啟服務後需重新產生。測試通過表示有 AI 工具透過 MCP 讀取了這個版本；系統無法辨認是哪個工具。任務結果仍需另外檢查。
    

    沒有成功連線？
    • AI 說沒有工具：回到「連接 AI」，檢查設定後開新工作階段。
    • AI 只回覆文字：請它實際呼叫 get_skill，並傳入測試指令的 verificationCode。
    • 顯示版本已變更：重新產生測試指令，驗證最新保存版。
    返回連接步驟 →

      腳本與參考資料（選用）
      先保存檔案，再加入目前步驟，最後保存 Skill。腳本由有相應工具與權限的 AI 執行。
