腳本與參考資料


腳本是可執行程式；參考資料提供規則或背景；素材是輸出會用到的文字模板。儲存檔案後，按「加入目前步驟」，最後保存並生成 Skill。







可建立 Python、PowerShell、JavaScript 等腳本。執行命令、所需 runtime、輸入與輸出請填在步驟指示／行動；agent 須有相應 runtime 及執行權限。Web 保存和 MCP 讀取均不會執行腳本。素材編輯目前支援文字，不支援二進位檔案上傳。
