      驗證連接
      測試 MCP 連線
      連接只需設定一次。這裏選一個 Skill 測試實際讀取，不是為每個 Skill 另建連接。
      

      連接驗證
      尚未開始
      1. 按「產生測試指令」。
      2. 複製並貼到你的 AI 對話，讓 AI 呼叫工具。
      3. 回來查看結果；等候期間每 3 秒更新。
      

      等待 MCP 讀取
      測試指令有效 15 分鐘，重啟服務後需重新產生。測試通過表示有 AI 工具透過 MCP 讀取了這個版本；系統無法辨認是哪個工具。任務結果仍需另外檢查。
      

      沒有成功連線？
      • AI 說沒有工具：回到「連接 AI」，檢查設定後開新工作階段。
      • AI 只回覆文字：請它實際呼叫 get_skill，並傳入測試指令的 verificationCode。
      • 顯示版本已變更：重新產生測試指令，驗證最新保存版。
      返回連接步驟 →

        這個 Skill 幫你做甚麼？
        小寫英文、數字及連字號。建立後用這個名稱呼叫 Skill。
        用一句話寫明這個 Skill 幫你完成甚麼、何時使用。AI 會用這段描述理解它的用途。
        進階：本機保存位置
        

        寫資料的種類，不是在這裏輸入一次性的任務。例如：「使用者的任務要求，以及相關檔案」。
        這是整個 Skill 的完成要求，會加入 AI 指示。例如：「交出修改建議，列出依據和仍未確定的問題」。與單一步驟的輸出可以不同。
        AI 要怎樣做？
        下面是 AI 會讀到的完整操作指示。你可修改要做的事、所需資料及完成條件；保存後整份指示生效，不分成可勾選步驟。格式設定放在下方進階區。
        進階：完整 Markdown 原始碼
        AI 要做哪些步驟？ 0
        點左邊名稱編輯步驟；用「上移／下移」調整順序。目前選了 0 步給 AI。勾選表示保存後會提供給 AI，未勾選的內容仍會保留。
        

        

        腳本與參考資料（選用）
        只有需要額外檔案才使用這一區。① 填檔名和內容，按「保存檔案」。② 按「加入目前步驟」。③ 最後保存 Skill。腳本由 AI 的工具執行，此頁不會執行。
        這是你要建立的檔案名稱，不是執行命令。腳本用 scripts/；背景資料用 references/；文字模板用 assets/。例如 references/rules.md。
        Web 不會執行腳本或安裝 runtime。圖片等二進位素材未支援上傳。
